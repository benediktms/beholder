## Why

After deterministic topology is proven useful, agents need bounded architecture-oriented inspection without downloading the UI's unbounded topology or treating optional model output as fact. This change adds progressive, exact-revision views and evaluates whether they improve agent outcomes.

## What Changes

- Add exact-revision Leiden context to intent inspection without requiring an overlay.
- Add bounded `architecture_map` with explicit semantic/Leiden/raw fallback, served level, origin, readiness, and omissions.
- Add witness-preserving architecture compression for already bounded trace and impact results.
- Run the preregistered five-arm evaluation and report adopt, revise, or stop from correctness and misleading-claim gates.

## Capabilities

### New Capabilities
- None.

### Modified Capabilities
- `agent-query-api`: Topology-aware intent inspection, progressive architecture map, compression, and comparative adoption requirements.

## Impact

Future implementation extends `crates/architecture-query` and additive MCP contracts after A and B are ready. It never aliases the UI snapshot, invokes a provider at query time, replaces raw evidence, or mixes derived data from another revision.

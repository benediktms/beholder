## Why

Structural communities may help orientation but are not stable architectural truth. Only if the useful-B gate passes, this change allows a bounded, optional interpretation layer whose evidence, identity, uncertainty, and failure modes remain separate from canonical data and topology.

## What Changes

- Add evidence-backed architecture units, reproducible bounded evidence packs, and explicit uncertain continuity events.
- Add an opt-in isolated provider protocol that validates and caches only whitelisted overlay suggestions.
- Permit conservative labels, parent assignments, shared/cross-cutting/orphan flags, and reversible suggestions; record merge/split ideas without applying them.
- Prohibit provider calls on query paths and preserve useful canonical/topology output when the overlay is absent or invalid.

## Capabilities

### New Capabilities
- `architecture-overlay`: Optional, derived semantic architecture interpretation contracts.

### Modified Capabilities
- None.

## Impact

Future work adds derived DTOs, pack construction, an isolated optional worker/protocol, and derived-state records. It reuses topology partitions and canonical evidence but cannot mutate Mnestic entities, observations, relationships, provenance, or revisions.
